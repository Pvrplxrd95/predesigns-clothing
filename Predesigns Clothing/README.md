# Predesigns Clothing Website

![Predesigns Clothing Logo](images/logo.jpg)

## About

Predesigns Clothing is a luxury streetwear and custom tailoring brand based in Hammanskraal, North of Pretoria, South Africa. Founded in 2019 by Josias Tlou, we specialize in high-quality, tailor-made clothing that combines urban elegance with traditional craftsmanship.

## Features

### 🎯 **Main Website (index.html)**

- **Hero Section** - Brand introduction with custom order CTA
- **About Section** - Company story and services overview
- **Collections Section** - Luxury streetwear, traditional wear, custom suits, and dresses & gowns
- **Lookbook Section** - Fashion inspiration and style stories
- **Services Section** - Comprehensive fashion solutions
- **Blog Section** - Fashion insights and trends
- **Contact Section** - Contact forms and information
- **Newsletter** - Subscription for updates and offers

### 🛍️ **E-commerce Functionality (shop.html)**

- **Product Catalog** - 18+ products across 4 categories
- **Advanced Filtering** - Category, price, and availability filters
- **Collection Navigation** - Direct links from collections to filtered products
- **Quick View Modals** - Product previews with details
- **Cart & Wishlist** - Local storage persistence
- **Custom Order Integration** - Seamless custom order requests

### 🎨 **Design & User Experience**

- **Mobile-First Design** - Fully responsive across all devices
- **Modern Aesthetic** - Luxury streetwear with traditional elements
- **Smooth Animations** - Professional transitions and interactions
- **SEO Optimized** - Meta tags and Open Graph integration
- **Performance Optimized** - Fast loading with preloader

## Getting Started

### Prerequisites

No special prerequisites required. The website runs entirely in the browser.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/predesigns-clothing.git
   ```

2. Navigate to the project directory:

   ```bash
   cd predesigns-clothing
   ```

3. Open `index.html` in your web browser:

   ```bash
   open index.html
   ```
